# EmpirioLabs AI for Claude

Run AI models, image, video and speech generation, web search and research with citations, batch jobs, GPU Cloud and hosted agents from Claude through the EmpirioLabs AI remote MCP server.

## Sign in

The plugin connects to the EmpirioLabs AI MCP server at `https://mcp.empiriolabs.ai/mcp`, with no API key to set. In Claude Code, run `/mcp`, choose `empiriolabs`, sign in to EmpirioLabs AI and choose **Allow access**.
